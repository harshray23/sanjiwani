
# Sanjeevani  
**Unified Digital Healthcare Platform with Blockchain Trust Layer & AI Triage**

## 🏥 Overview
**Sanjeevani** is a full-stack healthcare ecosystem designed to bring **hospitals, patients, doctors, and diagnostics** under a single digital roof. 

Unlike traditional systems, Sanjeevani uses the **Avalanche Blockchain** as a verification layer to ensure that critical data—such as ICU bed availability and blood stock—is tamper-proof and verifiable by the public. It further complements modern medicine with **AI-driven triage** and **AyurGenixAI** holistic supportive care.

## 🎯 Vision
To create a decentralized trust ecosystem where every individual has access to verified, real-time medical data, preventing the fatal misinformation that often occurs during health emergencies.

## ⚙️ Key Features
- **AI Clinical Decision Support (Triage)**
  - A structured multi-step triage engine using **Gemini 1.5 Flash**.
  - Provides risk assessments and correlates symptoms to diagnostic roadmaps.
- **AyurGenixAI Supportive Care**
  - Holistic recovery plans (Diet, Herbs, Yoga) mapped to 367 unique diseases.
  - Multilingual support (Hindi/Marathi) based on 446 patient records.
- **Avalanche Data Verification** (MAIN USE CASE)
  - Critical updates (Beds, Blood, Medical Records) are hashed and anchored to Avalanche.
  - Ensures a tamper-proof audit trail for medical resource availability.
- **Verified Blood Bank Network**
  - Real-time blood stock tracking with "Available/Limited/Critical" indicators.
  - Community donor matching system for emergency shortages.
- **Decentralized Incentive System**
  - Users earn **Sanjeevani Points** for verified community contributions.
  - Rewards are anchored to the Avalanche Fuji C-Chain.
- **Tokenized Appointment & Test Booking**
  - Razorpay-integrated secure payments for doctors and diagnostics.
  - Unique booking tokens for high-speed hospital check-ins.

## 🛠️ Total Complete Tech Stack
### **Frontend & UI**
- **Framework:** Next.js 14/15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Components:** ShadCN UI & Lucide Icons
- **Mapping:** Leaflet.js (Emergency Command Center)
- **Animations:** Lottie React

### **Backend & AI**
- **Server:** Next.js Server Actions & API Routes
- **GenAI Framework:** Google Genkit
- **LLM:** Gemini 1.5 Flash
- **Intelligent Chat:** Botpress (Multilingual Support)

### **Database & Auth**
- **Database:** Firebase Firestore (Real-time resource state)
- **Auth:** Firebase Authentication (Google & Password)

### **Trust Layer (Web3)**
- **Network:** Avalanche C-Chain (Fuji Testnet)
- **Interaction:** ethers.js
- **Development:** Hardhat (Smart Contracts)

### **Payments**
- **Gateway:** Razorpay (INR Settlements)

## 💎 The "Killer Explanation"
"We don’t use blockchain for storing healthcare data—that would be inefficient. Instead, we use Avalanche as a verification layer to ensure that critical hospital data like ICU beds and blood availability cannot be tampered with. This creates trust in a system where misinformation can cost lives."
