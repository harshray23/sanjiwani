
# Sanjeevani  
**Unified Digital Healthcare Platform with Blockchain Trust Layer**

## 🏥 Overview
**Sanjeevani** is a full-stack healthcare management platform designed to bring **hospitals, patients, doctors, clinics, and diagnostic laboratories** under a single digital ecosystem. 

Unlike traditional systems, Sanjeevani uses **Avalanche Blockchain** as a verification layer to ensure that critical data—such as ICU bed availability and blood stock—is tamper-proof and verifiable by the public.

## 🎯 Vision
To create a decentralized trust ecosystem where every individual has access to verified, real-time medical data, preventing the fatal misinformation that often occurs during health emergencies.

## 🏗️ Architecture
- **Frontend:** Next.js 14 (React) with Tailwind CSS & Lucide Icons
- **Backend:** Node.js API (Server Actions)
- **Database:** Firebase Firestore (Real-time resource state)
- **Trust Layer:** Avalanche C-Chain (Data anchoring & incentive rewards)

## ⚙️ Key Features
- **Avalanche Data Verification** (MAIN USE CASE)
  - Critical updates (Beds, Blood) are hashed and anchored to Avalanche.
  - Ensures a tamper-proof audit trail for medical resource availability.
- **Decentralized Incentive System**
  - Rewards for verified community contributors and blood donors.
  - Incentive tracking via smart contracts.
- **Tokenized Appointment Booking System**
  - Reduces waiting time and overcrowding with secure digital tokens.
- **Hospital Bed Booking**
  - Live availability verified on-chain.
- **Diagnostic Test Booking**
  - End-to-peer tracking of diagnostic progress.

## 💎 The "Killer Explanation"
"We don’t use blockchain for storing healthcare data—that would be inefficient. Instead, we use Avalanche as a verification layer to ensure that critical hospital data like ICU beds and blood availability cannot be tampered with. This creates trust in a system where misinformation can cost lives."
