# Sanjeevani  
**Unified Digital Healthcare Platform**

## 🏥 Overview
**Sanjeevani** is a full-stack healthcare management platform designed to bring **hospitals, patients, doctors, clinics, and diagnostic laboratories** under a single digital ecosystem.  
The platform aims to improve the efficiency, transparency, and accessibility of the medical system by enabling real-time availability, seamless appointment booking, and digital healthcare services.

## 🎯 Vision
To create a smart, transparent, and accessible healthcare system where patients can easily connect with medical services and healthcare providers can manage their resources efficiently.

## ⚙️ Key Features
- **Tokenized Appointment Booking System**
  - New and efficient token-based scheduling mechanism
  - Reduces waiting time and overcrowding

- **Online Digital Consultation**
  - Virtual doctor consultations
  - Secure and real-time interaction

- **Hospital Bed Booking**
  - Book hospital beds online
  - View live availability of beds across hospitals

- **Live Resource Availability**
  - Real-time availability of doctors, hospital facilities, and services

- **Diagnostic Test Booking**
  - Book medical tests at registered diagnostic centers
  - View test availability and details

- **Multi-role System**
  - Patient, Doctor, Hospital Admin, Diagnostic Center roles

## 🏗️ System Architecture
- **Frontend:** Next.js (React) with TypeScript  
- **Backend:** Node.js (API routes / server-side logic)  
- **Database:** Firebase Firestore (Real-time data)  

## 🛠️ Tech Stack
- Next.js  
- React  
- TypeScript  
- Node.js  
- Firebase Firestore  

## 📊 Database Structure (Firestore)
- `users` – Patients, Doctors, Admins  
- `hospitals` – Hospital details and facilities  
- `doctors` – Doctor profiles and availability  
- `appointments` – Tokenized appointment data  
- `beds` – Bed availability and booking records  
- `diagnostic_centers` – Lab information  
- `tests` – Diagnostic test details and bookings
